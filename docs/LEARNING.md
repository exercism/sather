# Learning

## Learn on Exercism

The track's concept exercises teach Sather one concept at a time, starting from no programming experience.
Each exercise's introduction explains the concept before you use it.
Once you've met a concept, practice exercises let you use it on larger problems.

## Background

For the ideas behind Sather's design, read [The Sather Programming Language][dr-dobbs] (PDF), by Stephen M. Omohundro, which appeared in Dr. Dobb's Journal in October 1993.
It describes an early version of Sather, so some details differ from the GNU Sather this track uses.

## Going further

The [GNU Sather tutorial][tutorial] covers the whole language with examples.

For the details of the language and its built-in classes, see [Useful Sather resources][resources].
