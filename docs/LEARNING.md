# Learning

## Start here

[The Sather Programming Language][dr-dobbs], by Stephen M. Omohundro, appeared in Dr. Dobb's Journal in October 1993.
It is a short introduction to the language and the reasons behind its design.
It describes an early version of Sather, so some details differ from the GNU Sather this track uses.

## Learn on Exercism

The track's concept exercises teach Sather one concept at a time, starting from no programming experience.
Each exercise's introduction explains the concept before you use it.

## Going further

The [GNU Sather tutorial][tutorial] covers the whole language with examples.
