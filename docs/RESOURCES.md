# Resources

## Reference

- [Built-in classes][builtin]: `INT`, `STR`, `ARRAY` and the other classes every program can use.
- [The GNU Sather tutorial][tutorial]: the language explained with examples.
- [The Sather specification][specification]: the full definition of the language.

## Background

- [The Sather Programming Language][dr-dobbs]: Stephen M. Omohundro's introduction in Dr. Dobb's Journal, October 1993.
- [Sather on Wikipedia][wikipedia]: the language's history.
- [GNU Sather releases][gnu-ftp]: the compiler and its libraries as source code.
  Reading a library class's source shows every routine it has.

## Getting help

- The [Exercism forum][forum] is the place to ask questions about the Sather track.
- After submitting a solution, you can [request mentoring][mentoring] to get feedback on it from a volunteer.
