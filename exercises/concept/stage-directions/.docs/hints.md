# Hints

## General

- The stub already declares every routine, each ending with its own
  `end;`. Replace each `raise "unimplemented";` with the real body.

## 1. Announce the start

- The answer is a piece of text, which is why the routine is declared
  `: STR`.
- Text goes between double quotes: `"like this"`.
- Hand the answer back with `return`.

## 2. Announce the interval

- The same shape as the first task, with different text.
- Copy the expected line exactly, including the full stops.

## 3. Announce the end

- Again the same shape.

## 4. Call the final cue

- Do not write the text a third time.
- Inside the same class you can use a routine by name, with no class name in
  front and no brackets, as `greeting_again` does in the introduction.
- Work out which of your routines already gives this line, and hand back
  whatever it answers.
